核对日期：2026-09-18。范围：IND-44 的验收标准和证据缺口。本文不代表实机验收通过，也不批准发布或付费请求。

本轮先收尾已有历史、整理模型和设置界面改动，准备下一轮小范围公测，不继续叠加功能。IND-67 暂缓；IND-53 保持现有采集路径，后续实验见[音频处理策略](audio-processing-policy.md)。

## 不可退让的行为

以下任一已复现问题均阻断候选；“本次未观察到”不等于证明总体发生率为零：

- 录音按下时冻结麦克风，录音结束时冻结 Input Target。丢失设备不得自动换麦，焦点变化不得改投其他目标。
- 安全输入目标不持久化转录正文；目标安全性未确认时也不得提前保存正文。音频不进入日常历史或文字整理供应商。
- 送达必须经过 `DeliveryCommitGate`；取消后的迟到结果不得送达，已提交的修改不得报告为取消，不得重复发送。
- 录音、供应商及资源耗尽错误准确记录；主动取消和过短录音不被记为同类故障。
- 权限缺失、错误 Key、设备中断必须可恢复；恢复不自动重启旧会话。

契约来源：[Voice Input 规范](../specs/voice-input.md)、[架构](../architecture.md)、[冻结麦克风 ADR](../adr/0008-freeze-the-capture-microphone.md)。

## 质量指标和分母

| 指标 | 口径 | 不能替代的证据 |
| --- | --- | --- |
| 完成与失败 | 保存每个计划样本及重复尝试；分别计启动失败、无文本、供应商失败、设备中断和观察截止时未完成。计划取消单列，非预期取消仍需解释 | 不能删除失败样本后宣称整体准确或成功 |
| CER / 拉丁词元 WER | 固定参考文本、归一化和分词规则；报告成功样本条件下的错误率，同时报告全部尝试数、失败数和每类样本分母 | 不同模式、不同参考不能直接混算 |
| 事实保真 | 独立检查数字、单位、否定、专名、标识符、遗漏及新增事实；记录样本级差异和人工判定 | 低平均 CER 不能抵消关键事实错误 |
| 松键后等待 | 同一时钟记录实际录音结束至最终可用结果的时长；分别统计转录、整理路径的 p50/p95，并给出样本量和未完成数 | 整次请求耗时不等于松键后延迟；小样本 p95 不代表稳定尾延迟 |
| 设备恢复 | 中断按预期结束；设备再次可用后能主动开始新会话；记录设备、系统及操作步骤 | 重连事件出现不等于录音可用 |
| 真实输入效果 | 在受控人工兼容测试中查看目标内容、重复插入、选区、撤销和焦点变化 | 系统已发送粘贴事件不证明目标输入框已插入文本 |

真实输入效果只作为受控验收证据，不恢复产品里的“粘贴成功/未确认”状态，也不要求日常用户逐次确认。历史保留最终内容与明确故障。

[SpeakerAccuracyEvaluator](../../Tools/SpeakerAccuracyEvaluator/main.swift)当前总体报告包含成功/失败数，但 CER/WER 只聚合成功样本；标签分组也只来自成功样本，全失败标签可能完全缺失。验收必须补齐所有计划标签及失败分母，将无成功样本的错误率标为不可用，不能填 0。成对均成功样本可作辅助比较，不能取代全量结果。

该工具的 `durationMilliseconds` 从实时分块发送前开始计时，包含音频发送时间。当前报告不能证明松键后的等待，更不能简单减去音频时长后当作精确测量。缺少实际时间戳时标为未测。

Default Smoothing 会调整口语表达，应与忠实识别分别设参考及验收；文字整理另查语义和事实。先在同一批获准样本、同一设备与服务配置上重复旧版基线，再与候选成对比较。质量和时延预算应在查看候选结果前，根据基线波动及用户场景确定；目前不编造统一 CER 或毫秒阈值。

## 覆盖与证据记录

核心语料覆盖普通话、中文夹英文、数字/单位/专名/否定、短句与长句、轻声及日常噪声。样本须获准且非敏感，参考和许可可追溯。真实录音或付费供应商实验须按[开发指南](../agents/development.md)另行授权；本轮仅制定标准。

矩阵按实际声明支持的组合记录：内置麦克风、耳麦/USB、iPhone 连续互通；最低支持 macOS 14 与当前系统；声明分发的 Intel/Apple Silicon 架构。未测组合明确标记，不用一台 Mac 推断全部。跨 App 覆盖继续遵循现有 TextEdit、Safari、Chrome/Electron、富文本和 Terminal 门禁。

每份证据绑定提交、干净源码状态、版本/build、可执行文件 SHA-256、签名类别、macOS、架构、设备、模型/资源、配置和时间。公开报告不含 Key、音频、转录正文或供应商原始消息。不同候选、旧模型和旧签名的报告不能移用。

本轮改动需重点回归：

- DMG 拖拽安装、首次权限引导、更新后权限与已有配置保留。
- 各供应商 Key 新增、更新、删除、来回切换；手填模型保留及推荐模型的真实可用性。
- 整理模式单选、自定义提示、错误与取消恢复；历史展开和明确错误展示，不出现粘贴推断或加入词库入口。
- macOS 26 玻璃界面及旧系统回退、深浅色、提高对比度、VoiceOver、窄窗口、Esc 关闭与短录音静默结束。

## 当前缺口与下一步

当前已有离线规格、AppKit UI 规格和本机安装证据；真实新模型、跨设备/系统、完整兼容矩阵与质量基线仍有缺口。默认测试为静默的非 UI 门禁；发布 CI 仍必须运行 `./scripts/test --with-ui`。UI 自动化不是用户机器上的权限、VoiceOver 或供应商验收。

下一步是审查并收敛候选、确定版本、提交与合并、取得 CI 全门禁和新 DMG，补齐候选绑定的公测前证据后再分发。正式发布继续等待固定身份、公证和升级证据。本文完成的是验收定义，不能据此将质量验证或发布任务标为完成。
