# Speaker 0.5.0 BETA

## 本次更新

- 修复历史和概览的刷新竞态：清空历史或再次刷新后，较早请求的结果不会覆盖当前记录、计数和用量。
- 降低离线准确率评测的长文本内存占用，保持原有计分和并列判定规则。2,500 字符本机测试夹具的进程峰值内存约从 60 MiB 降至 8 MiB。
- 加强评测 WAV 校验：拒绝截断文件、越界数据块、不完整 PCM 帧及不一致的音频格式，避免无效样本进入供应商请求。

## 安装

此安装包适用于 **Apple Silicon Mac（M 系列芯片），macOS 14 或更新版本**。

下载 `Speaker-0.5.0-development.dmg`，打开后将 Speaker 拖到“应用程序”，再从“应用程序”启动。更新前退出旧版 Speaker。

此版本为开发公测：采用 ad-hoc 签名，尚未公证，不进入自动更新通道。macOS 可能拦截首次打开，更新后也可能需要重新授予麦克风和辅助功能权限。

自动测试不代表所有真实设备、系统版本和供应商模型均已验收。内存测量来自离线测试夹具，不代表语音识别或供应商服务性能。
