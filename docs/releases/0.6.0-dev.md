# Speaker 0.6.0 BETA

## 本次更新

### 语音识别

- 语音识别可选豆包、OpenAI 或阿里千问，文字整理仍单独选择。旧配置继续使用豆包。每家服务商记住各自的模型；千问北京和新加坡地域分别保存 Key，OpenAI 的识别和文字整理使用各自的 Key。
- OpenAI 和千问可选流式识别（边录边传）或整段识别（录完再上传），模型列表随方式切换。单次录音上限：豆包 10 分钟，OpenAI 5 分钟，千问 3 分钟。
- 整段识别的音频只保存在内存里，本机录音检查通过后才上传。取消后丢弃晚到的结果；识别失败不会自动换用其他服务商。
- 历史记录保存实际使用的识别服务和模型。
- 修复 OpenAI 和千问流式识别在响应超过 1 MiB 时被报告为网络错误的问题。

### 界面

- 页面 Tab 移到标题栏，Tab 之间不再有分割线。切换时选中标记滑到新页面；开启“减弱动态效果”后直接切换。
- 卡片里的按钮、输入框和菜单改为液态玻璃胶囊，三者高度一致。
- “已开启”“已配置”等状态标签改为彩色圆形图标加文字。正常状态用浅色文字，需要处理的状态用正常文字颜色。
- ⌘, 和应用菜单里的“设置”打开主窗口的设置页，不再单独打开设置窗口。
- 设置页删去重复的说明文字，“关于”只显示 App 版本号。
- 动画统一使用同一条缓出曲线。概览的入场动画每次启动只播放一次。浮层的复制图标切换到完成状态时有过渡，所有动画都遵循“减弱动态效果”。

### 辅助功能

- 历史记录可以用键盘和 VoiceOver 展开，复制和删除可以通过 VoiceOver 操作或右键菜单完成。
- 历史搜索随输入过滤，清空搜索框后恢复完整列表。
- “增强对比度”覆盖状态标签、快捷键按键图示和录音提示。

### 修复

- 快速连续删除两个词典词条时，第一个词条不会被写回。
- 快速切换“登录时自动启动”时，注册和注销不会交错。
- 在 API Key 输入框中按回车即可保存。

## 安装

此安装包适用于 **Apple Silicon Mac（M 系列芯片），macOS 14 或更新版本**。

下载 `Speaker-0.6.0-development.dmg`，打开后将 Speaker 拖到“应用程序”，再从“应用程序”启动。更新前退出旧版 Speaker。

此版本为开发公测：采用 ad-hoc 签名，尚未公证，不进入自动更新通道。macOS 可能拦截首次打开，更新后也可能需要重新授予麦克风和辅助功能权限。

自动测试不代表所有真实设备、系统版本和供应商模型均已验收。本版本没有用付费接口实测 OpenAI 和千问，真实账号可用性、识别准确率和网络延迟仍需自行确认。
