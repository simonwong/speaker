# Speaker 0.10.0 Beta

## 从 0.9.0 更新

- Bundle ID 没有变化。权限、API Key、设置、个人词库和历史记录都会保留，不用重新走引导。
- 如果你从没在设置里改过“自动检查更新”，更新后第一次启动时 Speaker 会询问一次要不要自动检查更新。设置里开关过的不会再问。
- DeepSeek 的默认模型改为 `deepseek-flash`。没有手动选过模型的跟着改；已经选了 `deepseek-v4-flash` 的保持不变。

## 本次更新

### 多个自定义整理模式

- “设置 → 整理”里最多可以建 10 个自定义模式，每个有自己的名称和指令，可以改名、编辑、删除和调整顺序。
- 菜单栏里显示当前整理模式的那一项，展开后可以在全部内置和自定义模式之间切换。
- 删除正在使用的自定义模式后，回到默认顺滑。

### 更快

- 按下快捷键后，连接识别服务和启动麦克风同时进行。
- 需要整理时，提前连接整理服务。这次连接不带 Key，也不带任何文字；服务商能看到 IP 和时间，详见隐私说明。
- 精简清理模式下，不超过 10 个字、句末有标点、没有语气词或改口的单句直接用识别结果，不再请求整理。个人词库里有词条时不跳过。
- 整理请求把不变的规则和词库放在前面、识别文字放在最后，服务商可以命中缓存。长段文字的输出上限随长度增加，不再因为输出被截断而退回识别结果。
- 等待整理时，浮层上的“直接用识别结果”不再中途消失。

### 输入更可靠

- 剪贴板改为等目标 App 读到文字后再恢复，最多等 3 秒。远程桌面、虚拟机这类读得慢的 App 不会再贴进你原来的剪贴板内容。
- 输入框最后显示的内容既不是原内容也不是识别文字时，不自动重试，浮层提示“可能未正确输入，请先检查”。
- 剪贴板内容过大时不自动输入，浮层说明原因，文字可以手动复制。
- 自动粘贴前检查光标所在的元素能不能编辑，不能编辑时提示“没有检测到输入框”。
- 按当前键盘布局发送 ⌘V，非 QWERTY 布局也能粘贴。
- 全局快捷键改在单独线程处理。主线程忙时不再拖慢系统按键，也不会因此取消录音；空闲时不再拦截其他按键。
- Mac 睡眠唤醒、切换 Wi‑Fi 或 VPN 后，等待识别结果时能发现连接已断开并报网络问题，不再一直停在“等待结果”。适用于豆包、OpenAI 和千问。
- 修复按 Esc 后紧接着按快捷键有时没有反应。

### 隐私

- 自动输入用到的临时剪贴板内容不进剪贴板管理工具的历史，也不经“通用剪贴板”同步到其他设备。
- 浮层不会出现在截屏和屏幕共享里。
- 安全输入框（例如密码框）的待复制结果在浮层上显示“文字已隐藏，可直接复制”。
- 其他 App 开启了安全输入时按快捷键，浮层会提示，能识别时写出是哪个 App。
- 无法确认输入框类型的 App，历史记录不保存文字。
- 识别结果里的控制字符会被清掉。

### 首次使用

- 新安装时按这台 Mac 选默认识别服务：macOS 26 且支持本机识别时用 Apple 语音识别；否则系统语言是中文时用豆包，其他语言用 OpenAI。
- 引导最后一步可以开关自动检查更新，默认开启。
- 免 Key 的本机识别排在服务列表第一位。

### 界面

- 引导、设置、概览、历史记录、词库、关于和菜单栏统一了间距、按钮和提示样式，删掉了一批重复的说明文字。
- 整理页里，使用中的模式是珊瑚色描边，正在编辑但没启用的是金色描边。
- 录制新的录音快捷键时，按当前快捷键不会再开始录音；自定义快捷键可以“恢复默认”。
- “关于”页加入作者网站和工作室链接。

## 安装

适用于 Apple 芯片和 Intel 芯片的 Mac，要求 macOS 14 或更新版本。Apple 语音识别需要 macOS 26 或更新版本。

已安装 0.9.0 的用户可以在 Speaker 里检查更新。新安装时打开 DMG，把 Speaker 拖到“应用程序”，再从“应用程序”启动，按提示授予麦克风和辅助功能权限。也可以用 Homebrew 安装：

```bash
brew tap simonwong/speaker https://github.com/simonwong/speaker
brew install --cask simonwong/speaker/speaker
```

云端语音识别和文字整理使用你自己的 API Key，由所选服务商计费。

这是公测版。自动测试和签名校验通过，不代表所有设备、系统版本和服务商模型都已验收。
