# Speaker 0.4.1 公测版

## 本次更新

- 安装包改为 DMG，带 Speaker 图标和拖拽到“应用程序”的安装界面。
- 首次配置分步引导麦克风、辅助功能和 API Key，并加入快捷键操作说明。
- 文字整理支持 DeepSeek、OpenAI、Kimi、GLM，以及自定义 HTTPS 接口和模型 ID。各供应商独立保存 Key，切换后保留；模型推荐由 App 维护，手填模型保留。
- 修复 Key 更新与删除、整理模式选择和自定义模式高亮。
- 历史展开按最终结果、识别原文及诊断组织，移除加入词库和粘贴状态推断。
- 设置按钮和输入框适配 macOS 26 玻璃样式，旧系统保留兼容外观。
- 过短录音静默结束；提示支持 Esc 关闭，关闭控件与录音浮层保持一致。待复制结果可收起并开始下一次录音，已有内容可在历史中查找。

## 安装

下载 `Speaker-0.4.1-development.dmg`，打开后将 Speaker 拖到“应用程序”，再从“应用程序”启动。更新前退出旧版 Speaker。

此版本为开发公测：采用 ad-hoc 签名，尚未公证，不进入自动更新通道。macOS 可能拦截首次打开，更新后也可能需要重新授予麦克风和辅助功能权限。

自动测试不代表所有真实设备、系统版本和供应商模型均已验收。音频采集保持现有策略，本版不新增降噪功能。
