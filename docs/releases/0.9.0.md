# Speaker 0.9.0 Beta

## 从 0.8.0 更新

0.9.0 起 Speaker 的 Bundle ID 从 `cn.simonwong.speaker` 改为 `app.moonunder.speaker`。macOS 把更新后的 Speaker 当作一个新 App：

- 设置、个人词库、历史记录和登录时启动保留不变。
- 更新后会重新打开新手引导，需要再授予一次麦克风和辅助功能权限，并重新填写服务商 API Key。旧的 Key 不会被读取，所以不会弹出钥匙串密码框。
- “系统设置 → 隐私与安全性”的“麦克风”和“辅助功能”里会留下旧的 Speaker 条目，可以删掉。
- 旧的 Key 仍保存在钥匙串里。在 Speaker 里“清除本地数据并退出”时会一起删除，也可以在“钥匙串访问”里搜索 `cn.simonwong.speaker.provider-api-keys` 手动删除。

## 本次更新

### Apple 语音识别

- 新增语音识别服务“Apple 语音识别”，在本机识别，不需要 Key，录音不上传。
- 需要 macOS 26 或更新版本。首次使用前在设置里下载语言模型。

### 保住已识别的文字

- 等待文字整理时，把鼠标移到浮层上，可以点“直接用识别结果”跳过整理并输入。
- 识别完成后取消的会话，文字留在历史里，标记为“已取消，未输入”。
- 菜单栏新增“最近结果”，列出最近 5 条，点一下复制。
- 历史记录右键菜单可以复制整理前的识别结果。
- 浮层用不同颜色区分识别和整理阶段。整理失败、改为输入识别结果时，浮层提示 2 秒。

### 配置与引导

- 没有授权或没有填 Key 时，菜单栏图标和概览会提示，并直接打开对应设置，不用等按快捷键失败才发现。
- 每个服务商的 Key 输入框旁边有控制台链接；豆包另有“怎么申请？”指引，并注明资源的计费方式。
- 豆包报错时说明是资源未开通还是 Key 填错，以及怎么改。
- 新手引导里恢复豆包的“检查连接”按钮，第 3 步加了练习输入框。
- 快捷键用 Fn 而系统设置里 🌐 键会切换输入法、显示表情或启动听写时，引导和设置里会提示，并提供“打开键盘设置”。

### 主窗口

- ⌘1–⌘5 切换页面，⌘F 搜索历史。
- 更新到新版本后，概览顶部提示一次，可以打开更新说明。
- 删除或清理历史后，概览的累计统计不再减少。
- 删除词库词条后可以撤销。
- “词典”标签改名为“词库”，概览热力图补回图例。
- 设置页布局调整；“关于”页加入官网、反馈和作者信息，并恢复“复制诊断信息”。

### 修复

- 修复首次设置时误报“无法设置登录时自动启动”。
- 鼠标停在错误提示上时，提示不会自动关闭。
- 只有文字链接显示手型光标。

## 安装

适用于 Apple 芯片和 Intel 芯片的 Mac，要求 macOS 14 或更新版本。Apple 语音识别需要 macOS 26 或更新版本。

已安装 0.8.0 的用户可以在 Speaker 里检查更新。新安装时打开 DMG，把 Speaker 拖到“应用程序”，再从“应用程序”启动，按提示授予麦克风和辅助功能权限。

云端语音识别和文字整理使用你自己的 API Key，由所选服务商计费。

这是公测版。自动测试和签名校验通过，不代表所有设备、系统版本和服务商模型都已验收。
