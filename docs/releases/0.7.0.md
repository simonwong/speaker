# Speaker 0.7.0

Speaker 是 macOS 菜单栏语音输入工具。按住全局快捷键录音，松开后识别文字，并按设置整理后输入到目标应用。

## 功能

- 支持豆包、OpenAI 和千问语音识别，可选择流式或完整录音识别方式。
- 支持可选文本整理、个人词库、历史记录和麦克风选择。
- 录音达到时长上限时自动结束并继续识别，最后 30 秒显示剩余时间。
- 提供服务商连接检查与内容脱敏的诊断信息。

## 安装与更新

适用于 Apple Silicon 和 Intel Mac，要求 macOS 14 或更新版本。

打开 DMG，将 Speaker 拖入“应用程序”，再启动。首次使用按提示授予麦克风与辅助功能权限。
语音识别和文本整理使用用户自己的 API Key，由所选服务商计费。

正式 Bundle ID 为 `cn.simonwong.speaker`。从 `com.local.speaker` 开发版迁移属于不同应用身份，
可能需要重新授权；不能保证开发版权限直接继承。正式版本将服务商凭据存入 macOS Keychain，
通过带签名验证的更新通道获取后续版本。
