# Speaker 0.8.0 Beta

## 本次更新

### 正式签名

- Speaker 改用 Apple Developer ID 签名，并经过 Apple 公证。下载后可以直接打开，不再需要在终端移除隔离属性。
- 同一个安装包支持 Apple 芯片和 Intel 芯片的 Mac。
- 服务商 API Key 改存在 macOS 钥匙串。
- 以后的正式版本可以在 App 内检查更新获取，安装包和更新信息都经过签名校验。

### 录音与提示

- 录音中没有检测到声音时，浮层直接收起，不再弹出提示。历史记录里仍保留这次录音及其错误标记，方便排查麦克风。
- 不需要去设置处理的提示，5 秒后自动消失。需要去设置处理的提示和待复制的结果，仍保留到你操作为止。

### 文本整理

- 口述内容里的要求、禁止事项和限制条件会作为正文保留下来，不会被当成给整理服务的指令执行或省略。

## 从开发版迁移

0.7.0 及更早的公测版是开发版，0.8.0 起是正式版。macOS 把两者当作不同的 App。

- 设置、个人词库和历史记录保留不变。
- 首次启动时，Speaker 会把已保存的 API Key 转存到钥匙串，然后删除旧的本地文件。如果之后设置里显示未配置 Key，重新填写一次即可。
- 麦克风和辅助功能权限需要重新授予一次。如果“系统设置 → 隐私与安全性 → 辅助功能”里留有旧的 Speaker 条目，可以删掉。也可以在终端只清除开发版的旧授权：

```bash
tccutil reset Accessibility com.local.speaker
tccutil reset Microphone com.local.speaker
```

- 开发版不会自动升级到正式版，需要手动下载安装一次。

## 安装

适用于 Apple 芯片和 Intel 芯片的 Mac，要求 macOS 14 或更新版本。

先退出旧版 Speaker。打开 DMG，把 Speaker 拖到“应用程序”替换旧版，再从“应用程序”启动。首次使用按提示授予麦克风和辅助功能权限。

语音识别和文本整理使用你自己的 API Key，由所选服务商计费。

这是公测版。自动测试和签名校验通过，不代表所有设备、系统版本和服务商模型都已验收。
