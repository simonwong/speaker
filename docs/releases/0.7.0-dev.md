# Speaker 0.7.0 BETA

## 本次更新

### 录音上限

- 录音到上限时自动结束，按松开快捷键处理：已录的内容照常识别、整理，并输入到当时所在的输入框。以前到上限会直接失败，录音全部丢弃。
- 上限：豆包 10 分钟；OpenAI 和千问比服务商的限制早 2 秒结束，分别是 4 分 58 秒和 2 分 58 秒。
- 最后 30 秒，录音浮层用“还剩 N 秒”代替音量条；鼠标悬停显示按钮时只显示“N 秒”。到上限时浮层会提示，VoiceOver 也会播报。
- 服务商仍然拒收的过长录音，提示改为“请分成几段较短的录音再试”。

### 设置

- 豆包的配置并入“语音识别”卡片，和 OpenAI、千问的配置方式一致。
- 保存过 Key 后，设置里只显示一行：状态、检查连接、更换 Key。点“更换 Key”才展开输入框。
- 整理模式和提示词合成一张卡片，整理服务商移到“整理”分区。
- 已开启、已配置、连接正常用柔和的绿色，未配置、检查中用灰色，只有需要处理的状态用橙色和红色。快捷键正常时不再显示“已启用”。
- “清除本地数据”卡片的红色减弱。
- 按钮和其他可点击的控件显示手形光标。

### 新图标与颜色

- 新 App 图标：浅色底上，珊瑚色和金色两层笔画错开叠印。菜单栏图标也改为两层。
- 珊瑚色成为主题色，用在保存等主按钮、开关、选中状态和输入框聚焦边框上。其他按钮保持中性色；“检查连接”“更换 Key”不再显示为蓝色链接。
- 录音浮层的音量条改为珊瑚色。
- 概览的柱状图和热力图，浅色模式用金色到珊瑚色的渐变，深色模式用珊瑚色的深浅。去掉“每日说出 · 近 52 周”标题和“少/多”图例，三项统计的说明文字调淡。

### 录音浮层

- 录音和处理中的浮层变窄，两端改为正圆。
- 报错和待复制的浮层宽度随文字长短变化。

## 安装

此安装包适用于 **Apple Silicon Mac（M 系列芯片），macOS 14 或更新版本**。

下载 `Speaker-0.7.0-arm64.dmg`，打开后将 Speaker 拖到“应用程序”，再从“应用程序”启动。更新前退出旧版 Speaker。

此版本为开发公测：采用 ad-hoc 签名，尚未公证，不进入自动更新通道。macOS 可能拦截首次打开，更新后也可能需要重新授予麦克风和辅助功能权限。

自动测试不代表所有真实设备、系统版本和供应商模型均已验收。本版本没有用付费接口实测录音到上限后的识别，真实账号下的表现仍需自行确认。
